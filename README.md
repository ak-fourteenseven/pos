# 餐飲店本地 POS 系統

專為餐飲門店設計的輕量級 POS（銷售終端）系統。**無需雲端伺服器**，所有資料與業務邏輯均在本地運行：斷網可用、資料隱私性高、無持續雲端訂閱成本。

## 技術架構

| 層級 | 選用 |
| --- | --- |
| 本地資料庫 | SQLite（Node 內建 `node:sqlite`，零原生編譯依賴），資料檔案 `server/data/pos.db` |
| 服務端 | Node.js + Express REST API（埠號 3001） |
| 前端 | Vue 3（Composition API）+ Vite + Tailwind CSS + Pinia + Vue Router |
| 圖表 / 匯出 | 自繪 SVG 圖表 + SheetJS（Excel）/ CSV 匯出 |

> 文檔建議的 Tauri/Electron 桌面殼可在本專案基礎上直接套用（前端已支援 `vite build` 後由服務端託管 `dist`）。

## 快速開始

```bash
# 1. 安裝依賴（首次）
npm run setup

# 2. 啟動前後端（開發模式）
npm run dev
# 服務端 http://localhost:3001  前端 http://localhost:5173
```

瀏覽器開啟 <http://localhost:5173>，使用測試帳號登入（初始密碼皆為 `123456`）：

| 帳號 | 密碼 | 角色 |
| --- | --- | --- |
| `admin` | `123456` | 店長（全部權限） |
| `cashier` | `123456` | 收銀員 |
| `cashier2` | `123456` | 收銀員 |

## 功能模組

- **前台收銀**：分類切換 / 菜品網格（售罄標記）、購物車（數量、備註、規格）、折扣/抹零/服務費、多種支付方式（現金找零計算機）、開台/換桌/併桌、桌台狀態視覺化（空閒/用餐中/待清/預訂）、掛單/取單、退菜、作廢訂單、今日訂單查詢、結帳小票預覽。
- **後台管理**：菜品管理（分類/規格/條碼/emoji/顏色/上下架）、桌台管理（區域/容納人數/狀態）、支付方式設定（啟用停用/手續費率）、員工與權限（收銀員/店長、重設密碼）、門店資訊設定。
- **報表統計**：日結單、月報表（每日趨勢）、菜品銷量排行 + ABC 分析、支付方式佔比、時段分佈、交接班報表，支援匯出 CSV / Excel。
- **系統維護**：一鍵備份（自訂資料夾或伺服器預備份目錄）、下載資料庫、還原備份、資料庫資訊。

## 目錄結構

```
POS-dev/
├── package.json          # 一鍵啟動/安裝腳本
├── server/               # 本地服務端
│   ├── src/db.js         #   SQLite schema + 種子資料
│   ├── src/index.js      #   REST API
│   └── data/pos.db       #   本地資料庫（運行後生成）
└── client/               # Vue 3 前端
    └── src/
        ├── views/        #   登入/收銀台/桌台/報表/各後台頁面
        ├── components/   #   Modal、SVG 圖表
        ├── stores/       #   Pinia：auth/pos/catalog/shift/toast
        └── utils/        #   格式化、CSV/Excel 匯出
```

## 注意事項

- 本機應用透過登入頭部傳遞身份，適合單店內網使用；如需對外開放請另加認證層。
- 首次啟動會自動建立資料庫並寫入示範資料（18 個菜品、12 張桌台、3 個員工）。
- 刪除 `server/data/pos.db` 即可重置為初始示範資料。
