# 餐飲 POS 系統點餐流程與業務邏輯設計 (基於實際菜單)

> 本文檔由實體菜單圖片提煉，已全部落地到系統實作中（套餐向導、配料階梯計價、飲品時段計價引擎、廚房單/收銀單雙視圖）。

## 1. 菜單結構分析與資料建模

根據實體菜單，系統資料結構需支援「套餐組合」與「單品」兩種模式。

### 1.1 核心分類 (Categories)
1.  **湯底 (Soup Base)**：單價 $35 (如：雲南酸辣、招牌酸麻辣、清湯等)。
2.  **麵類 (Noodles)**：預設 $0 (烏冬 +$2，芽菜底 $0)。
3.  **辣度 (Spiciness)**：屬性選項，非獨立計費項目 (清湯不適用)。
4.  **湯餃 (Dumplings)**：單價 $45 (淨湯餃10隻 / 湯餃上海麵)。
5.  **配料 (Toppings)**：分階梯計價 ($7, $8, $9, $11)。
6.  **飲品 (Drinks)**：跟餐價 ($7-$10)，受時段與冷熱屬性影響。
7.  **精美小食 (Snacks)**：獨立計價單品 ($16-$38)。

### 1.2 飲品計價規則引擎 (Pricing Engine)
飲品價格非固定，需根據「時段」與「冷熱屬性」動態計算：
*   **下午茶時段**：所有冷熱飲品均 **$0 (免費贈送)**。
*   **午市 / 晚市時段**：
    *   **熱飲**：**$0 (免費)**。
    *   **冷飲**：原價 **+ $3** (例如原價 $7 的凍奶茶，實收 $10)。

## 2. 點餐 UI 交互流程設計

POS 前台介面採用「向導式 (Wizard)」設計，引導店員快速完成點餐。

### 2.1 流程一：湯底套餐點餐 (主流程)
1.  **Step 1: 選擇湯底**（菜品網格中直接點擊，即為套餐基礎品項）
    *   6 種湯底 (雲南酸辣、招牌酸麻辣、四川麻辣、香濃沙嗲、清湯、熱拌)。
    *   *邏輯*：選擇「清湯」時，向導自動跳過「辣度」步驟。
2.  **Step 2: 選擇麵類**
    *   8 種麵類。選擇「烏冬」時，訂單總額自動 +$2。
3.  **Step 3: 選擇辣度**
    *   8 種辣度 (唔辣 至 勁辣)。若 Step 1 選清湯，則此步自動跳過。
4.  **Step 4: 選擇配料 (Toppings)**
    *   按價格分組展示 ($7/$8/$9/$11 配料)。多選，即時更新總價。
5.  **Step 5: 選擇飲品**
    *   提供「凍/熱」切換，系統自動抓取當前時間判斷時段計價。
    *   附加選項：口味勾選 (走甜/少甜/多甜/走冰/少冰/多冰)。

### 2.2 流程二：湯餃套餐點餐
1.  **Step 1: 選擇湯餃類型**：淨湯餃10隻 ($45) / 湯餃上海麵(6隻餃子) ($45)。
2.  **Step 2: 選擇餃子餡料**：韭菜餃 / 粟米餃 (必選單選)。
3.  **Step 3: 選擇飲品**：邏輯同「流程一 Step 5」。

### 2.3 流程三：單點小食
*   直接在「精美小食」分區點擊添加。
*   部分小食 (如麻辣牛柏葉、爽脆豬耳) 彈出辣度/口味選擇框 (小辣/中辣/大辣 或 滷水/麻辣/香辣)。

## 3. 購物車與訂單資料結構

購物車中的單一訂單項目 (Order Item) 採用嵌套結構，儲存於 `order_items.options`（JSON）：

```json
{
  "item_type": "combo",
  "product_name": "招牌酸麻辣",
  "price": 63,
  "quantity": 1,
  "options": {
    "base": "招牌酸麻辣",
    "noodle": { "name": "幼薯粉", "price_diff": 0 },
    "spiciness": { "name": "中辣", "price_diff": 0 },
    "toppings": [
      { "name": "肥牛", "price_diff": 11 },
      { "name": "炸魚蛋", "price_diff": 7 }
    ],
    "drink": {
      "product_id": 9,
      "name": "奶茶",
      "base_price": 7,
      "temperature": "COLD",
      "final_price": 10,
      "period": "晚市",
      "preferences": ["少甜", "走冰"]
    }
  }
}
```

> 價格由後端計價引擎覆核計算（`computeComboUnitPrice`），前端展示與後端落庫一致，防止改價。

## 4. 系統設定與時段管理

後台「系統設定 → 時段設定」可自訂三個時間段：
*   **午市**：11:00 - 15:00 (冷飲 +$3，熱飲免費)
*   **下午茶**：15:00 - 18:00 (冷熱全免)
*   **晚市**：18:00 - 23:00 (冷飲 +$3，熱飲免費)

### 4.1 前端即時計算邏輯

```javascript
// 實現：client/src/utils/pricing.js
function drinkPrice(basePrice, temperature, slot) {
  if (!slot) return basePrice;
  if (slot.drink_all_free) return 0;              // 下午茶全免
  if (temperature === 'HOT') return slot.drink_hot_free ? 0 : basePrice;
  return basePrice + slot.drink_cold_extra;       // 午晚市冷飲加價
}
```

## 5. 列印小票格式 (ESC/POS)

結帳完成後的小票彈窗提供雙視圖：

### 5.1 廚房單（後廚/水吧）
```text
【廚房單】POS20261016-0005 · 桌台 A1
【廚房】
1x 招牌酸麻辣
     麵: 幼薯粉
     辣度: 中辣
     加料: 肥牛, 炸魚蛋

【水吧】
1x 奶茶 (凍, 少甜, 走冰)
```

### 5.2 收銀單（顧客）
*   明細清晰：套餐基礎價、加料費分項列出。
*   優惠顯示：飲品免費時顯示「飲品時段優惠：原價 $7，優惠 −$7」，讓顧客感知到優惠。

> 實際硬體列印（ESC/POS 印表機、錢箱、客顯）需在桌面殼（Tauri/Electron）中接入本地外殼程式；當前版本提供完整的列印內容預覽。
